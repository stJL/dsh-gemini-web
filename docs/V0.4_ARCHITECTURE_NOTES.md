# v0.4.0 Architecture Notes & Refactoring Consensus

> **Baseline**: Branched from `main` at `v0.3.0-beta.1` (`abf0512`), where Free-tier & PRO end-to-end flows (`AI Studio`, `Gemini Web Chat/Task`, `Google Flow`, `Lyria`, `Wave`) are all verified and working.  
> **Long-term Goal**: Establish a clean, long-lived foundation (`0.4.0-alpha.*` -> `beta.*`) by **carving away regex/wrapper bloat** rather than piling on new heavyweight features.

---

## 1. Core Consensus (不可動搖的大方向)

> **「只守最基本的安全門禁 + 把上游變成給 DSH 主 AI 自由調度的獨立多 Agent 算力平台。」**

- **Stop fighting upstream (`@582835293/gemini-web-agent`)**:
  - `scripts/gemini_web.py` and `scripts/gemini_agentlimb.py` are the execution engine.
  - Instead of hardcoding TypeScript `if/else` forms and regexes for every new upstream flag or playbook, keep the DSH wrapper thin so `scripts/sync_upstream.py` stays low-friction.
- **Trust strong host models + GUI config**:
  - Inject the user's authorized GUI settings (`~/.dsh/gemini-web-config.json`: allowed model ladder, `thinkingPolicy`, `thinkingLevel`, `connectionMode`, `directorMode`) directly into the gate/context.
  - After the user approves the confirmation gate, the host AI reads `SKILL.md` and `references/` (`director_prompt.md`, `models.md`, `agentlimb.md`, `playbooks/*.md`) and composes single tasks or `Wave` specs freely within the user's GUI-authorized boundaries.

---

## 2. Core Assets to KEEP (雕刻時不可誤傷的護城河)

1. **Ask-Before-Dispatch Confirmation Gate (`src/index.ts`)**:
   - `previewedTaskMap` / `confirmed` guard + `ask_question` / `ask_user_question` interactive buttons.
   - Multi-turn anti-inertia: every new task resets to confirmation unless `fast_track` is explicitly enabled.
2. **GUI Fallback Ladder & Free-Tier Anti-Billing Locks (`src/config.ts`, `src/bridge/agent-executor.ts`, `client.js`)**:
   - User-editable 1–5 model ladder, strict mode, and `--fallback-model none` when calling upstream `playground` (prevents silent escalation to paid models).
   - Dynamic account scanning (`Paid` filtering, free `Extra High` safety lock, PRO automatic unlock for `Neon` / `Lyria` / `Task`).
3. **Dual-Channel Transport & AgentLimb Resilience (`src/bridge/detector.ts`, `scripts/agentlimb_client.py`, `scripts/gemini_agentlimb.py`)**:
   - Channel A (AgentLimb zero-popup, multi-port scan skipping `revoked` ports) prioritized over Channel B (Chromium CDP).
   - Fast-fail on `503 / high demand` and `google.com/sorry` CAPTCHA (`captcha_blocked: true`, never auto-bypass).
4. **Long-Code File-Link Delivery (`src/index.ts`)**:
   - Save generated code/media to `downloads/` and return clickable `file:///` links + concise summary so host models never hit SSE truncation (`Incomplete JSON segment`).
5. **DSH Native GUI & Chat-Room Slots (`client.js`, `src/transport/router.ts`)**:
   - Live status indicator, quota dashboard (AI Studio / Gemini Web / Flow), Playbook manager, Deliverable Review drawer, and `enableChatSlots`.
6. **Session Isolation, Secret Guardrails & Test Net (`src/bridge/agent-executor.ts`, `scripts/sync_upstream.py`, `tests/`)**:
   - `.gemini-teams/<sessionId>/` isolated `roster.json` and `wave_<timestamp>/` sandboxes with explicit user merge.
   - `isSensitiveSecretFile()` blocking `.env`, `*.pem`, `*.key`, `id_rsa*`, credential JSONs from networked `gemini-spark` tasks.

---

## 3. What to Carve Away in v0.4.x (雕刻刀修剪目標)

- **Slim down `src/proposal.ts`**:
  - Retire brittle keyword/regex guessing (e.g. guessing Playbook type, model alias, or channel from dozens of regexes) as the primary path for strong models.
  - Keep a lightweight fallback path only if needed for small models or deterministic preview formatting, while letting strong host models pass structured `site`, `entry`, `model`, `wave_spec`, etc. cleanly.
- **Simplify system prompt / tool description sprawl (`src/index.ts`, `SKILL.md`)**:
  - Replace defensive, repetitive all-caps rules aimed at weak 8B models with crisp, composable tool contracts and clear reference pointers.
- **Clean executor interface (`src/bridge/agent-executor.ts`)**:
  - Allow the host AI (post-confirmation) to pass structured Wave / Playbook / multi-tab tasks cleanly without fighting the wrapper, while enforcing the safety rails (GUI config limits, `--fallback-model none`, secret file filter, session isolation) unconditionally in code.

---

## 4. Brake-Check Rules (何時該提醒用戶剎車)

Whenever a proposed change falls into any of these patterns, **stop and flag it before implementing**:
1. **Regex Creep**: Adding new regex rules to guess user intent instead of letting the host AI specify parameters.
2. **Feature Bloat / Competing Orchestrator**: Building custom scheduling engines or heavy UI workflows that duplicate what `gemini_web.py` / `gemini_agentlimb.py` or the host AI already handles.
3. **Hidden Coupling Against Upstream**: Patching around upstream behavior in ways that will break `scripts/sync_upstream.py` on the next upstream update, unless it is a strict safety boundary.
4. **Safety Boundary Erosion**: Any shortcut that bypasses the confirmation gate (outside explicit `fast_track`), risks silent paid-model billing, or leaks local secrets to networked `Task` sandboxes.

## 5. Versioning Decision Note
- Branch starts as `feat/v0.4.0-alpha.1-agent-platform` (baseline `package.json` still reads `0.3.0-beta.1`).
- **Do not finalize the version bump until the refactoring diff is complete**:
  - If changes are incremental cleanup / partial slimming -> consider `0.3.1-alpha.1` or `0.4.0-alpha.1`.
  - If `proposal.ts` + tool contracts + prompt layer are substantially simplified into the new light-gate agent platform -> bump to `0.4.0-alpha.1` (matching `docs/VERSIONING_GUIDE.md` minor architectural evolution rules).
